# Canonical chart fonts

The renderer loads these local files, independent of installed system fonts.

- Jua Regular: rounded Korean display title. Source: https://github.com/google/fonts/tree/main/ofl/jua
- Noto Sans KR Regular (400) and Bold (700): body, events, and legend. Static weight instances generated with fontTools from https://github.com/google/fonts/blob/main/ofl/notosanskr/NotoSansKR%5Bwght%5D.ttf

Both are distributed under the included SIL Open Font License files. These fonts approximate the supplied reference's typography; they are not claimed to be its original fonts.
