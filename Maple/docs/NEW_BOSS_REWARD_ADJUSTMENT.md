# 신규 보스 추가에 따른 보상 기회 증가 반영

2026-09-12. 관측 생산량은 그대로 두고, **같은 접근 가능 보스 목록과 같은 가격표**에서 신규 보스가 생겨 늘어나는 수입을 계산했다. 이지 대적자만 일반 신규 보스 중 챌섭 접근 가능 예외로 두고, 다른 신규 보스는 본섭 접근 목록에 넣었다. 카이·메이린은 종전대로 하드 세렌 이하 3구간이다.

## 1. 계산 원칙

- 가격 기준은 2026-08-20이다. 2025-04-17, 2025-10-23, 2026-06-18 공식 가격표를 이어 현재 가격을 구성했다.
- 벨로나 이지/노멀은 2026-09-10 테스트 공지의 **기존 가격 열**로 8월 가격을 확인했다. 이후 예정된 너프 가격은 사용하지 않았다.
- 캐릭터별 같은 보스는 가장 높은 접근 가능 난이도 하나만 선택한다. 서로 다른 난이도를 두 번 더하지 않는다.
- 수익 상위 12개만 선택한다. 신규 보스가 들어와 밀려난 기존 결정석을 빼서 순증분을 계산한다.
- 월간 검은 마법사는 이 주간 보상 목록에서 제외한다.
- 본섭 다캐릭 예시는 캐릭터별 12개 선택 후 월드/계정 90개 제한을 추가 적용했다. 실제 캐릭터 수 분포를 관측했다고 주장하지 않는다.

이 결과는 **고정가격·고정 접근 목록의 보상 기회 지수**다. 출시 당시 실제 원화/메소 수입이나 전체 유저 평균의 직접 추정이 아니다. 플레이어의 스펙이 변하지 않아도 보상이 늘어나는 구조를 별도로 잡는 목적이다. 접근 목록은 비교 시나리오이며 환산 수치별 도달 가능성을 새로 검증한 자료가 아니다.

## 3. 실제 계산된 보상 기회

8/20 가격을 양쪽에 동일 적용하고 접근 가능한 캐릭터 자체는 고정했다.

| 접근 목록 | 신규 보스 제외, 주당 | 출시된 신규 보스 포함, 주당 | 증가 |
|---|---:|---:|---:|
| 챌섭 하드 세렌 범위, 이지 대적자 포함 | 12.4408억 | 15.4280억 | **+24.01%** |
| 챌섭 익스트림 스우 범위, 신규는 이지 대적자만 | 23.5930억 | 26.5420억 | **+12.50%** |
| 본섭 익스트림 스우 범위, 노멀 대적자·이지 벨로나 포함 | 23.5930억 | 32.9730억 | **+39.76%** |
| 본섭 노멀 림보 범위, 노멀 흉성·벨로나 포함 | 36.7320억 | 55.2660억 | **+50.46%** |
| 지정한 최상위 보스 접근 목록 | 158.1920억 | 316.4840억 | **+100.06%** |

최상위 목록은 선정한 보스들을 솔로로 잡는 경우의 계산 예이며 일반적인 상위 유저 평균이 아니다. 하드 벨로나 가격은 이번에 확보한 공식 표에서 확인하지 못해 그 난이도는 목록에서 제외했고, 이지/노멀 벨로나만 사용했다. 목록이 더 완전해지면 해당 지수도 갱신한다.

대표적으로 챌섭 하드 세렌 목록에 이지 대적자가 추가되면 카오스 벨룸이 밀려난다.

`308,000,000 - 9,280,000 = 298,720,000 메소/주`

즉 순증분은 **2.9872억/주**다. 이지 대적자 결정석 3.08억을 전액 순증분으로 더하지 않았다. 이 계산은 **8/20 동일 가격 조건**이며 2025년 출시 당시 가격으로 계산한 금액은 아니다.

## 4. 분해 모형에 적용한 위치

관측 생산량을 가격 지수로 나눠 원본을 고치지 않았다. 추가 보상은 실제 생산이므로 그대로 남긴다.

1. 상위 본섭 구간을 하위 본섭의 성장 통제로 사용할 때, 지정한 본섭 상위 목록의 보상 기회 지수로 나눠 비교한다. 신규 보스가 추가된 효과 전부를 스펙 상승으로 하위에 전달하지 않는다.
2. 챌섭의 계정당 성장 경로를 규제할 때, 같은 시즌 직전 대비 챌섭 보상 기회 지수로 표준화한다. 이지 대적자 출시로 얻는 수입 증가를 모두 성장/해방 효과로 읽지 않는다.
3. 이지 대적자 출시가 포함된 국소 구간에는 매끄러운 생산경로 제약을 풀어, 신규 보스와 기존 보상 대체에 따른 변화를 허용한다.
4. 일반 신규 보스의 챌섭 목록에는 이지 대적자만 포함한다. 집계된 한 구간 안의 노멀 대적자 등 개별 보스 판매량은 별도로 관측되지 않았으므로 해당 보스의 실제 생산액을 임의 생성해 배분하지 않는다.

전체 기회 적용, 절반 적용, 미적용을 포함해 13시나리오×4시즌=52회 적합을 수행했다. 적용 비율은 실제 달성자 비율 관측값이 아니라 민감도 설정이다.

## 5. 결과가 얼마나 바뀌었나

- 리프 전 하위 1~2구간 증가분은 변하지 않는다. 지목된 일반 신규 보스 출시는 모두 각 시즌 첫 리프 이후 또는 같은 날이며, 기존 하드 equality anchor도 유지했다.
- S1: 기준 분해 변화 없음.
- S2: 이지 대적자가 시즌 중 추가되므로 일부 변화. 가장 큰 변화는 2025-10-30의 챌섭 몫 **-0.706%p**. 11/13 마지막 관측은 **8.748% → 8.336%**.
- S3: 기준 분해 변화 없음. 새 흉성·유피테르는 사용자 가정상 본섭 상위 접근 목록이며, 기준 모형이 본섭 상위의 증가를 하위에 그대로 전달하지 않기 때문이다. 상위 통제를 쓰는 대안에는 보정이 적용된다.
- S4: 기준 8/20 기여율 **36.4995% 유지**, 챌섭/본섭 계정 평균 비율 약 **55.7% 유지**. 이지 대적자는 시즌4 개장 전에 이미 존재했고, 나머지 일반 신규 보스는 챌섭 목록에서 제외했기 때문이다.
- 보정된 S4 시나리오 중심값 범위는 약 **33.42~39.27%**다. 통계적 신뢰구간이 아니다.

기준값이 거의 같다는 것은 보정이 누락됐다는 뜻이 아니다. 원래 기준 모형은 해당 상위 구간을 이미 본섭에 배분하고, 본섭 하위 생산을 상위 생산률과 기계적으로 연동하지 않았다. 바뀌어야 할 주된 부분은 상위 성장의 해석과 그런 연동을 사용하는 대안이다.

## 6. 회귀도 재계산

관측 하위 생산의 차분 회귀에 본섭 신규 보상 기회 변화와 공유되는 이지 대적자 기회 변화를 별도 변수로 넣었다. 상위 통제도 보상 기회 증가를 제거한 값으로 사용했다.

하위 생산에 대한 챌섭 인구 변화 계수는 기존 **0.3386 → 0.3453**, HAC p는 **0.1146 → 0.1081**이다. 방향과 통계적 판정은 크게 달라지지 않는다. 보상 기회 지수를 넣었다는 이유로 인과적으로 식별됐다고 주장하지 않는다.
