# 251016 원본 총생산과 저장 정본 직접 대조

사용자가 제공한 `251016 총메소.png`를 직접 읽었다. 그림 해상도1782×1000, 빨간 총생산선의 픽셀을2px 간격으로 판독했다. 빨간 결정석 조정 세로 글자는 데이터가 아니므로 해당 영역을 제외했다. 날짜축은 Jan/Jul2023~2025의 인쇄 눈금 중심6개로 보정했다. 기존 JSON과 그림을 맞추기 위한 날짜 이동은 최적화하지 않았다.

저장 정본과 원본y좌표 사이에 `P=a*(-y)+b`를 적합한 결과:

- a=1.48619638, b=1156.82966
- 저장 정본의 P=0에 대응하는 원본y 약778.38
- 평균 절대 상대오차1.3079%, RMSE4.612(NEW AGE 총생산=100 단위)

**이는 원본 총생산선의 모양과 기존 정본이 대체로 일치한다는 진단**이다. 전체 구간에 배율과 절편을 적합했으므로 OOS 정확도가 아니다. 원본에0값 눈금이 표시되지 않으므로 추정된y778.38이 실제 경제적0임을 증명하지 않는다. 기존 JSON이 바뀌지 않았음은 해시63e41f7c7d5c384971524a56df0dcc01a25fd888f808e9174b3195feb9dd6b41로 확인했다.

250410 합계의 영점 가능성도 검사했다. 앞선2024년4~6월 보정 구간에만 배율·절편을 적합하면 slope0.43550364, intercept10.22108이다. NEXT 이후 오차는 기존 단일배율16.2864%에서12.9211%로 감소하지만 사라지지 않는다. 모든5성분이 같은 영점 오차를 가졌다는 단순 가정하에서는 영점y830.69에 대응한다. 실제 도입 전0 계열은 이 단순 환산을 따르지 않으므로 물리적 영점 확정값으로 사용하지 않는다.
