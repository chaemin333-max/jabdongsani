# 250410 재판독 결과

2026-09-12. 기존 총생산 정본을 고정하고 판독 오류와 성분 범위를 다시 검사했다.

## 확인된 오류와 수정

초기 이미지에서 보스선의 밝은 테두리가 필드 분홍색과 비슷해 **15개 샘플에서 보스를 필드로 중복 판독**했다. 필드가 보스보다 아래에 있다는 원본의 공간적 관계를 적용해 수정했다. 청색 주화는 색과 원본에서 직접 읽은 연한 곡선의 위치 가이드를 함께 적용했다. 가이드는 정본 값으로 맞추지 않았다. 도입 전0인 계열의 후보 좌표를 QA 그림에 그리던 혼란도 제거했다.

수정판은 `_v2` 경로에 별도 저장했다. 기존 결과는 비교용이며 최신 판독으로 취급하지 않는다. 단위 보정 구간(2024년4~6월), 배율0.46130061, 날짜 눈금과 영점은 유지했다. 최종 그림과 원본 위 추적점 모두 육안 검사했다.

## 차이가 발생하는 시점

| 구간 | 다섯 성분 합계 MAPE |
|---|---:|
| 2024년7월~아즈모스 도입 전 | 1.90% |
| 아즈모스 도입 후~NEXT 전 | 8.78% |
| 2025년1월 이후 | 16.29% |

NEXT 이후 아즈모스 주화만 제외하는 사후 진단에서는2.98%, 다른 주화만 제외하면3.53%다. 이 결과는 ‘차이가 주화 등장과 연관된다’는 단서이지 주화 삭제를 정당화하는 증거가 아니다. 하나를 빼서 정본에 맞추지 않았다. 주화가 함께 변하므로 제외 실험만으로 어느 계열이 문제인지 식별할 수 없다.

## 현재 결론

**초기 판독 오류는 실제로 있었으며 수정했다. 그러나 나머지 불일치의 원인은 미확정이다.** 아즈모스 도입을 전후로 차이가 커지므로 주화 포함 범위와 기존 정본의 합산 원출처 확인이 우선이다. 복원 JSON이 가리키는 `meso_total_boss_share_data.json`은 현재 작업 트리와 해당 파일명의 git 이력 검색에서 찾지 못했다. 해시 일치는 저장된 정본 파일의 무결성을 증명할 뿐 그 파일의 경제적 정의가 정확함을 증명하지 않는다.

이번 결과를 근거로 사냥선 연장이나 기존 전체 생산량을 수정하지 않았다. v2 역시 예측 OOS/PASS가 아니라 독립 이미지 대조다. 원인 미확정 상태를 유지한다.
