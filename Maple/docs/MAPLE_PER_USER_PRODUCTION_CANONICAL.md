# 메이플 1인당 메소 생산량 정본 데이터

## 1. 목적

이 문서는 총 메소 생산량을 활동 유저 수로 나누어, 인구 효과를 제거한 생산성 지표를 만들기 위한 정본 스키마를 정의한다.

현재 확보된 본섭 활동인구는 메애기 `group1`이며 에오스·헬리오스는 제외되어 있다.

## 2. 기호

- `I_t`: 총 메소 생산량 상대지수
- `B_t`: 보스 메소 생산량 상대지수
- `A_t`: 본섭 활동유저 수 = 메애기 `group1`
- `C_t`: 챌린저스 활동유저 수
- `O_t`: 본섭과 챌린저스를 모두 이용한 중복유저 수
- `U_t`: 실제 unique active users

실제 유저 수는 `U_t = A_t + C_t - O_t`.

`O_t`를 직접 관측할 수 없으므로 `A_t <= U_t <= A_t + C_t`.

따라서 실제 1인당 총생산량은

`I_t / (A_t + C_t) <= I_t / U_t <= I_t / A_t`

범위 안에 있다.

- 상한 `I_t/A_t`: 챌린저스 유저가 전부 기존 본섭 유저라고 보는 극단
- 하한 `I_t/(A_t+C_t)`: 챌린저스 유저가 전부 본섭과 다른 사람이라고 보는 극단

## 3. 현재 계산값

현재 정본 CSV에는 본섭 기준 `I_t/A_t`, `B_t/A_t`와 챌린저스용 열 스키마가 포함된다. 챌린저스 주간 시계열을 확보하면 lower/upper bound를 채운다.

## 4. 정규화

2025년 9월 평균 `I_t/A_t`를 100으로 정규화한다.

`Q_t = 100 * (I_t/A_t) / mean_2025_09(I/A)`

보스 생산량도 같은 기준값으로 나눠 총생산과 동일 y축에서 비교한다.

## 5. 주의사항

1. 이 지표는 활동 유저 수 기준이며 활성 생산 캐릭터 수 기준이 아니다.
2. 한 유저가 여러 캐릭터로 보스를 도는 구조 때문에 엄밀한 캐릭터 생산성 지표가 아니라 유저당 경제 생산노출 지표에 가깝다.
3. 챌린저스 overlap을 알 수 없으면 단일 point estimate보다 식별구간 band를 정본으로 사용한다.
4. 과거 보스 시계열은 direct가 없는 구간에 한해 conditional backcast를 사용한다.
