## 2. 생산처별 선: 53주 복원

`production_by_source_weekly.csv`: 2025-08-21~2026-08-20의 53시점 × 5생산처.

0축 y=714와 범례 색을 기준으로 선 위치를 읽었다. 보스 리워드의 흐린 가장자리를 필드 선으로 잘못 읽지 않도록 각 선의 원본상 y범위를 명시했다. 보스 리워드에서 기존 정본으로 정한 하나의 세로 배율을 다른 생산처에도 동일 적용했다.

보스 리워드는 53시점 모두 추출했다. 다른 선끼리 겹치는 일부 시점은 빈칸을 유지한다. 기타는 0축 근처에서 분리되지 않아 정확한 0으로 확정하지 않고 해상도상 3pixel 이하로 기록했다. 총생산으로 자동 합산해 기존 정본을 덮어쓰지 않았다.

**주간 보스 구간 합계와 생산처별 보스 리워드는 동일하다고 강제로 맞추지 않았다.** 기존 주간 B와 새 막대 합계의 중앙 상대 차이는 약 2.57%지만 일부 시점은 20% 이상 다르다. 첨부 막대의 매끄러운 후반 상승과 생산처별 선의 국소 고점은 실제 모양도 다르다. 집계 대상(주간/시즌/기타 보스)·기간 및 시즌 보상 포함 범위를 확인하기 전 차이 전부를 메이린 생산으로 간주하지 않는다.

## 3. 솔로 격파 분포와 직접 비교 수치

`solo_clear_distribution.csv`: 2026-02-12, 2026-08-20의 6구간 비중과 공식 증감률.

증감률은 순서대로 -37%, -27%, +144%, +171%, +153%, +894%다. 이는 위 생산량의 전년 대비 증감률과 비교 기간도 지표도 다르다.

원본 두 막대의 비중을 픽셀로 측정했다. 표의 증감률을 구간별 **인원 증감률**로 해석하면 `p_new_j = r_j*p_old_j/G`, `G=sum(r_j*p_old_j)`가 성립한다. 이 관계 아래 두 막대와의 수정량을 최소화하여 비중을 구했다. 비중 수정은 최대 약 0.316%p다.

이때 분류 대상 총인원 배율 G≈1.552가 도출된다. 이는 **해당 솔로 격파 분류 모집단의 추론값**이지 공식 발표된 전체 활동인구 증가율이 아니다. 전/후 비중 합계 100%, 각 구간 인원 배율과의 일관성을 검사했다.

생산 구간 표는 보스별 메소를 분류하고, 솔로 격파 분포는 유저의 최고 격파 수준을 분류한다. 상위 유저가 하위 보스도 생산하므로 둘을 같은 색이라고 직접 나누지 않는다. 또한 솔로 분포 마지막 구간은 익스트림 세렌 **이상**이어서 생산표의 6+7구간에 해당하는 넓은 묶음이다.

## 4. 리프 전 구간별 증가분: 실제 계산

`preleap_tier_excess.csv`에 S1/S2/S3 각 4주, S4 5주, 총 17주를 계산했다.

기본식:

`C_low2(t) = [B_1(t)+B_2(t)] - [B_1(pre)+B_2(pre)]`

여기서 pre는 개장 직전 주다. 이 값은 사용자 가정 아래 챌섭의 **하드 진 힐라 이하 생산분**이며 챌섭의 모든 생산량이라고 단정하지 않는다.

추가로 상한 이하 본섭 합계도 고정한다고 놓는 경우:

`C_cap(t) = sum_{j<=cap}(B_j(t)-B_j(pre))`

S1~3 cap=3, S4 cap=4다. 상한 밖의 현재 생산은 본섭으로 남는다. 세 주 평균 baseline과 본섭 하위 합계 ±5% 변화 대안도 같은 파일에 저장했다. 기본 결과는 본섭 변화 0이며 대안은 기본값을 바꾸지 않는다. 음수는 자동으로 0으로 잘라내지 않는다.

각 시즌 첫 리프 직전 마지막 주에서 상한 이하 본섭 합계 고정까지 적용한 조건부 챌섭 생산 몫은 약 S1 26.5%, S2 38.2%, S3 10.8%, S4 33.1%다. 이는 **리프 전 마지막 주의 해당 주간 보스 구간 합계에 대한 값**이며 시즌 평균·8월 종점·시즌 보스 포함 전체 생산 몫이 아니다. 인구가 실제 관측된 날짜에는 해당 생산량/C도 함께 저장했다. 개장 첫날 인구가 없는 경우 평균 생산량은 비워 둔다.

1. 이번 7구간 시계열을 기본 관측으로 사용한다. 합계 하나로 축약하지 않는다.
2. 첫 리프 전의 위 증가분을 초기 챌섭 생산 경로의 기준으로 삼는다.
3. 시즌별 상한 위 구간은 본섭 전용 관측으로 사용한다.
4. 리프 이후에는 해당 캐릭터의 본섭 이동을 반영한다. 초기의 본섭 하위 고정 가정을 시즌 전체로 그대로 연장하지 않는다.
5. S2/S3 달성 정본과 시즌별 해방 경로를 결합하되, 최고 격파 구간→실제 하위 보스 생산의 연결을 유지한다.
