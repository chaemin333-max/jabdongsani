## Archival rule

- User and assistant messages that remain visible in the active conversation context are preserved in the numbered parts below.
- Where the conversation system had already replaced earlier turns with `Skipped ... messages`, the exact hidden original text could not be recovered; those locations are marked `[CONTEXT GAP]` rather than reconstructed from memory.
- System/developer instructions, private reasoning, and tool-call payloads are not included.
- Image-only assistant turns are represented as `[IMAGE RESPONSE]` when the active transcript contains no separate textual answer. They are not silently rewritten as prose.
- Sandbox artifact links are preserved as they appeared in the chat even though those runtime paths are not permanent GitHub assets.
- The final archival request itself is included at the end of Part 11. The assistant’s completion message necessarily comes after the archive files are written and is therefore not part of this snapshot.
