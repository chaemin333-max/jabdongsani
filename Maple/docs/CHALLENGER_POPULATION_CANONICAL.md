# 챌린저스 인구 보정 정본

## 정의

- `A_t`: 메애기 group1 활동유저 수. 에오스·헬리오스 제외.
- `C_t`: 메애기 챌린저스 아이템 버닝 캐릭터 수.
- 시즌별 아이템 버닝 캐릭터는 계정당 1개이므로 `C_t`를 챌린저스 활동계정 수 proxy로 사용한다.
- `O_t`: 본섭과 챌린저스를 동시에 이용한 중복 계정 수.
- `U_t = A_t + C_t - O_t`: 실제 unique active users.

중복계정 `O_t`는 직접 관측되지 않으므로

`A_t <= U_t <= A_t + C_t`

따라서 실제 1인당 총 메소 생산량은

`I_t/(A_t+C_t) <= I_t/U_t <= I_t/A_t`

범위 안에 있다.

동일하게 보스 생산량은

`B_t/(A_t+C_t) <= B_t/U_t <= B_t/A_t`

이다.

## 해석

- 상한 `I_t/A_t`: 챌린저스 유저가 전부 기존 본섭 유저라고 가정.
- 하한 `I_t/(A_t+C_t)`: 챌린저스 유저가 전부 본섭과 다른 신규/독립 유저라고 가정.
- 실제 값은 두 선 사이에 반드시 존재한다.
- `A_t+C_t` 자체는 unique population이 아니라 `world-user exposure`로 해석할 수 있다.

## 현재 확보 범위

메애기 RSC payload에서 직접 확보한 챌린저스 시즌1:

- 2024-12-19 ~ 2025-05-15
- 주간 22개 관측치
- 첫 관측: 173,213
- 최고: 351,168 (2025-01-02)
- 마지막: 45,589

시즌2~4는 현재 대화에 저장된 RSC 원문에는 포함되지 않아 임의 추정하지 않는다. 해당 탭의 동일 endpoint 원시값이 확보되면 같은 스키마에 그대로 append한다.

## 정규화

1인당 생산량 index는 기존 정본과 동일하게 `2025년 9월 평균 (총생산 / group1 활동유저) = 100`을 공통 기준으로 사용한다.

하한/상한도 같은 기준값으로 나누어 동일 y축에서 비교한다.
